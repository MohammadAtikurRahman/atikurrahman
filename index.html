THE DATABASE

Local data.
Less setup.

A portable database for Node.js and Windows apps. Connect from your application and work with documents without a separate database installation.

I built the SDK and surrounding tools to handle engine startup, encrypted storage, collections, and an easier connection experience.

  • Native engine integration
  • Encrypted storage
  • Node.js
Explore BsonLite Core source ↗
app.cjs
const BsonLite = require('bsonlite-sdk');

async function main() {
  try {
    await BsonLite.connect();
    const notes = BsonLite.collection('notes');

    await notes.insertOne({
      title: 'Made with BsonLite',
      completed: false
    });
  } finally {
    await BsonLite.stop();
  }
}

main().catch(console.error);

Windows x64 · Node.js · single-file or npm SDK
