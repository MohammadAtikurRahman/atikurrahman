DATABASE / FOUNDER’S PROJECT

BsonLite

A portable database for Node.js and Windows apps. Connect from your application and work with documents without installing a separate database server.

I built the SDK and surrounding tools to handle engine startup, encrypted storage, collections, and easier connections.

  • Native engine integration
  • Encrypted storage
  • Node.js
Visit BsonLite Core source ↗

BsonLite is an independent project using a custom MongoDB-based engine. Query support follows the bundled engine version and the SDK’s exposed API.

NPM PACKAGE

BsonLite SDK

The npm distribution of BsonLite, with a collection API, bundled engine, CommonJS and ESM imports, and automatic discovery by Console after your app starts.

npm install bsonlite-sdk
  • JavaScript
  • npm
  • Windows
Engineering details

Verifies published entry points, exact SDK bytes, native source, and notices. Windows integration checks the packed npm artifact through discovery, reads, write controls, and cleanup.

View on npm ↗Source ↗
DESKTOP + TERMINAL

BsonLite Console & CLI

An Electron database workspace with a terminal companion. Discover running apps, connect by URL, browse collections, edit documents, manage indexes, and run queries.

CLI EXAMPLEbsonlite --eval
"db.notes.find({}).limit(5)"
  • Electron
  • BSON
  • CLI
Engineering details

Includes token-authenticated local connections, an isolated renderer, a BSON-aware expression interpreter, and read-only client defaults. The portable Windows app and CLI tarball are available as a preview, with full source and build instructions.
